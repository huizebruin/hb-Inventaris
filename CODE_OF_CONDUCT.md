# Gedragscode / Code of Conduct

🇳🇱 Nederlands · 🇬🇧 English (hieronder / below)

## 🇳🇱 Nederlands

Dit project volgt de [Contributor Covenant 2.1](https://www.contributor-covenant.org/nl/version/2/1/code_of_conduct/).

**Kort gezegd:** wees vriendelijk en respectvol, ook als je het ergens niet mee eens bent. Geen intimidatie, discriminatie,
beledigingen of persoonlijke aanvallen. Geef kritiek op de code of het idee, niet op de persoon. Help elkaar; iedereen is ooit begonnen.

Ongewenst gedrag melden kan privé via de contactgegevens op [Huizebruin.nl](https://huizebruin.nl) of via een privé-bericht
aan [@huizebruin](https://github.com/huizebruin). De beheerder bekijkt elke melding vertrouwelijk en kan bijdragen verwijderen,
reacties modereren of deelnemers uitsluiten.

## 🇬🇧 English

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**In short:** be kind and respectful, even when you disagree. No harassment, discrimination, insults or personal attacks.
Critique the code or the idea, not the person. Help each other; everyone started somewhere.

You can report unacceptable behavior privately via the contact details on [Huizebruin.nl](https://huizebruin.nl) or by
messaging [@huizebruin](https://github.com/huizebruin) privately. Every report is handled confidentially; the maintainer may remove
contributions, moderate comments or ban participants.
