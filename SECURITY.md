# Beveiliging / Security

🇳🇱 Nederlands · 🇬🇧 English (hieronder / below)

## 🇳🇱 Nederlands

**Meld kwetsbaarheden niet als openbaar issue.** Gebruik in plaats daarvan *Security → Report a vulnerability*
([privé melden](../../security/advisories/new)) of neem privé contact op via [Huizebruin.nl](https://huizebruin.nl).
Vermeld de versie (*Menu → Beheer & gezondheid → Overzicht*), wat je ziet, en hoe het te reproduceren is.
Je krijgt zo snel mogelijk een reactie; een fix volgt in een nieuwe versie met vermelding in de [changelog](CHANGELOG.md).

Ondersteund: de nieuwste versie. Deze app is bedoeld voor gebruik op je eigen netwerk; lees
[docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) voordat je hem via internet bereikbaar maakt.

## 🇬🇧 English

**Please don't report vulnerabilities as public issues.** Use *Security → Report a vulnerability*
([private report](../../security/advisories/new)) or contact me privately via [Huizebruin.nl](https://huizebruin.nl).
Include the version (*Menu → Admin & health → Overview*), what you observed and how to reproduce it.
You'll get a reply as soon as possible; a fix ships in a new version, noted in the [changelog](CHANGELOG.en.md).

Supported: the latest version. This app is meant for your own network; read
[docs/DEPLOYMENT.en.md](docs/DEPLOYMENT.en.md) before exposing it to the internet.
