💡 Tips
📷 QR scanner — open een onderdeel → tab "📷 Scan" → kies modus: zoeken, +1 of −1
⧉ Onderdeel kopiëren — open detail → "⧉ Kopieer" om snel een vergelijkbaar onderdeel aan te maken
☑ Bulk acties — vink meerdere rijen aan voor bulk locatie/categorie/voorraad/labels
🏷 Tags — voeg tags toe aan onderdelen, filter via #tag in de zoekbalk
💾 Backup — automatisch elke nacht om middernacht, laatste 7 bewaard
📐 Foto's — worden automatisch verkleind bij upload. Check via 🖼 Media → 📦 Te groot
📱 PWA — installeer via browser (Android: ⋮ → "Toevoegen aan startscherm")
